# 🛡️ Кибер-Гранит.ИИ

Автономный учебный портал цифровой безопасности для воспитанников военно-патриотических клубов Республики Беларусь, с собственным офлайн-модулем искусственного интеллекта.

**Автор:** Голубева Дарина Вячеславовна, 224 СШ г. Минска, военно-патриотический клуб «Гранит».

## О проекте

Портал в игровой и интерактивной форме учит:
- распознавать фишинг, вербовку, социальную инженерию и голосовые ИИ-дипфейки;
- противодействовать ИПсО и фейкам;
- безопасно вести себя в соцсетях (риски OSINT, геометки/EXIF — с реальной проверкой своих фото);
- создавать и хранить надёжные пароли;
- соблюдать законодательство Республики Беларусь в цифровой среде.

Всё закрепляется в интерактивном 7-этапном квесте «Кибер-Полигон: Операция «Цифровой Щит»» (включая этап про ИИ-подделку голоса).

Проект существует в двух версиях:
- **`Cyber_Granit.html`** — единый автономный HTML-файл. Открывается двойным кликом в любом браузере, **не требует интернета, сервера или установки чего-либо**. Это основной, портативный артефакт проекта.
- **`app.py`** — исходная версия на Python/Streamlit (`streamlit run app.py`).

## 🤖 ИИ-модуль

В 2026 году портал дополнен пятью собственными офлайн-моделями машинного обучения, обученными «с нуля» на чистом Python (без sklearn/PyTorch и без интернета) и один в один портированными на JavaScript — так, что `Cyber_Granit.html` остаётся полностью автономным (веса моделей встроены прямо в файл, ни одного сетевого запроса).

| Модель | Алгоритм | Метрика |
|---|---|---|
| Классификатор угроз в сообщениях (фишинг / вербовка / ИПсО / безопасно) | **Ансамбль из 2 независимых моделей:** наивный байес (символьные n-граммы) + многоклассовая логистическая регрессия (softmax, градиентный спуск) | 98,0% accuracy (отложенная выборка), модели согласны в 96% случаев |
| ИИ-скоринг риска OSINT-публикации | Тот же ансамбль из 2 моделей, 2 класса | 100% accuracy |
| AI-оценка предсказуемости пароля | Символьная n-граммная языковая модель (марковская цепь 3-го порядка) | дополняет классическую проверку энтропии |
| ИИ-консультант портала | TF-IDF + косинусное сходство по базе знаний (18 Q&A) | retrieval-based, без генерации текста |

Когда обе модели ансамбля расходятся во мнении, интерфейс честно показывает это пользователю, а не скрывает за усреднённой цифрой.

Подробности архитектуры, датасетов и метрик — в [`ai_models/MODEL_CARD.md`](ai_models/MODEL_CARD.md).

Модели используются:
- как отдельный раздел **«🤖 ИИ-Ассистент»** (анализатор сообщений, OSINT-скоринг, чат);
- как встроенные виджеты в разделах «Анти-Фишинг», «ИПсО и Фейки», «ОСИНТ и Соцсети», «Пароль-контроль»;
- как кнопка **«🤖 Запросить ИИ-анализ сообщения»** прямо внутри квеста «Кибер-Полигон» (этапы 1, 4, 7).

## 🔬 EXIF/GPS-анализатор (не ИИ, но реальный алгоритм)

В разделе «ОСИНТ и Соцсети» можно загрузить свою фотографию (JPEG) — скрипт разбирает бинарный формат файла «с нуля» (без библиотек в браузерной версии) и показывает, зашиты ли в нём GPS-координаты, дата съёмки и модель камеры. Файл не покидает устройство: разбор происходит локально через `FileReader`/Pillow. Наглядно подтверждает урок про геометки практическим инструментом.

## Запуск

**HTML-версия (рекомендуется):** просто откройте [`Cyber_Granit.html`](Cyber_Granit.html) в браузере (Chrome/Firefox/Edge/Safari 90+). Интернет не требуется.

**Python/Streamlit-версия:**
```bash
pip install streamlit
python ai_models/build_models.py       # обучить ИИ-модели (генерирует ai_models/*.json)
streamlit run app.py
```

**Пересборка HTML после изменения ИИ-моделей:**
```bash
python ai_models/build_models.py
python ai_models/inject_into_html.py   # встраивает свежие веса в Cyber_Granit.html
```

## Структура репозитория

```
Cyber_Granit.html          — автономная HTML-версия (весь функционал + ИИ-модели внутри файла)
app.py                     — версия на Python/Streamlit
images/                    — иллюстрации (сгенерированы нейросетью NanoBanana Pro)
ai_models/
  datasets.py               — обучающие датасеты (синтетические, см. пояснение в файле)
  nb_engine.py               — общий движок: наивный байес, логистическая регрессия,
                                n-граммная языковая модель, TF-IDF
  build_models.py            — обучение всех 5 моделей, метрики, экспорт JSON
  inject_into_html.py        — встраивание весов в Cyber_Granit.html (идемпотентно)
  MODEL_CARD.md               — отчёт об обучении (архитектура, метрики, примеры)
  *.json                      — обученные веса моделей (NB + LogReg для 2 классификаторов + password LM)
tests/
  test_ai_parity.py           — сверяет Python- и JS-версии моделей на контрольных примерах
  test_build.py                — дымовой тест обучения (accuracy не ниже порога)
.github/workflows/ci.yml    — GitHub Actions: тесты гоняются на каждый push
```

## Технологический стек

Без сторонних ML-библиотек и без интернета в рантайме: чистый Python (`re`, `math`, `collections`, `json`) для обучения, чистый JavaScript (ES6, без фреймворков) для инференса в браузере.

## Лицензия / использование

Учебный проект, подготовлен для участия в конкурсах по кибербезопасности и искусственному интеллекту в Республике Беларусь.

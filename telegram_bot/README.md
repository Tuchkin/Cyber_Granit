# 📱 Кибер-Гранит.ИИ — онлайн-режим (Telegram-бот)

Дополнительный, необязательный канал к основному офлайн-полигону. Работает
поверх Telegram Bot API — то есть **требует интернет**, в отличие от
`Cyber_Granit.html` и `app.py`. Использует те же самые обученные ИИ-модели
из `../ai_models/*.json` через общий движок `../ai_models/nb_engine.py` —
никакой отдельной логики, никакого дублирования.

## Зачем это нужно

Основной полигон (HTML/Streamlit) — самостоятельный, offline-first продукт;
онлайн-режим его не заменяет и не требуется для прохождения квеста. Он даёт
дополнительный охват: посетитель форума может отсканировать QR-код на стенде
и задать вопрос ИИ-консультанту или проверить подозрительное сообщение прямо
со своего телефона, без установки чего-либо.

## Что делает бот

- `/start` — приветствие и меню из 4 режимов.
- **🔍 Проверить сообщение** — тот же ансамбль (наивный байес + логрег), что и в разделе «ИИ-Ассистент».
- **👁️ Оценить риск OSINT** — тот же скоринг риска утечки.
- **🔐 Оценить пароль** — та же символьная языковая модель предсказуемости.
- **💬 Задать вопрос** — тот же TF-IDF-консультант по базе знаний, с корректной обработкой вопросов не по теме.

## Запуск

1. Создайте бота: в Telegram напишите **@BotFather** → `/newbot` → задайте
   имя и username (должен заканчиваться на `bot`, например `CyberGranitBot`).
   BotFather выдаст токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

2. Установите зависимости (нужен интернет только на этом шаге):
   ```bash
   pip install -r requirements.txt
   ```

3. Укажите токен переменной окружения и запустите бота:
   ```bash
   # Windows PowerShell:
   $env:TELEGRAM_BOT_TOKEN="ваш_токен"
   python bot.py

   # Windows cmd:
   set TELEGRAM_BOT_TOKEN=ваш_токен
   python bot.py

   # Linux/macOS:
   export TELEGRAM_BOT_TOKEN=ваш_токен
   python bot.py
   ```
   Бот работает через long polling — публичный сервер/домен/порт не нужны,
   достаточно исходящего доступа в интернет с того компьютера, где он запущен
   (можно даже с телефона через Termux, или с обычного ноутбука на форуме).

4. Сгенерируйте QR-код на бота (username без `@`):
   ```bash
   python generate_qr.py CyberGranitBot
   ```
   Файл сохранится в `telegram_bot/qr-code.png` и `../images/telegram-bot-qr.png`
   — второй путь подхватится автоматически в разделе «ИИ-Ассистент» портала
   (и в HTML-, и в Streamlit-версии).

## Важно про приватность

В отличие от браузерной/Streamlit-версий, сообщения в Telegram сохраняются в
истории переписки — бот в приветствии явно предупреждает не присылать
реальные пароли и личные данные, только тестовые примеры.

## Постоянная работа (после конкурса)

Пока бот запущен только на время демонстрации — этого достаточно для форума.
Если понадобится, чтобы бот работал постоянно (а не только пока запущен
`bot.py` на чьём-то компьютере), его можно развернуть на VPS или бесплатном
хостинге с поддержкой долгоживущих процессов (значение имеет только
исходящий доступ в интернет, входящий трафик/домен не нужны, т.к. используется
polling, а не webhook). Это отдельное решение по инфраструктуре — код бота
для этого менять не придётся.
